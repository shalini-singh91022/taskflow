# TaskFlow – Task Management Web Application

TaskFlow is a full-stack task management web application that allows users to create, view, update, complete, search, filter, and delete tasks.

The project was built to practice backend development, REST APIs, MongoDB database integration, and deployment.

## Live Demo

https://taskflow-esi3.onrender.com

## GitHub Repository

https://github.com/shalini-singh91022/taskflow

---

## Features

- Create new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks by title
- Filter tasks by status
- Set task priority
- Set task due dates
- Input validation
- Error handling
- Persistent data storage using MongoDB
- Deployed using Render
